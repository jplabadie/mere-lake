# Founding set

Same shape as [Agentic Foundry](https://github.com/jplabadie/agentic-foundry). The extra rules are the lake: fixtures for the totals, and a check that the buckets stay private.

| File | What it binds |
| --- | --- |
| `manifest.json` | Phases, checks, layers, dataset, revision |
| `fixtures.json` | Invariant hash, order totals, Terraform checksum |
| `09-scorecard.md` | Rubric |
| `01-principles.md` | Invariants |
