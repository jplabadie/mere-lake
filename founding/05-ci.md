# CI

Jobs, named as the manifest requires:

- `bedrock` runs the founding check.
- `analytics` runs the local summary against the fixtures.
- `terraform` installs Terraform 1.9.8, checks the checksum in the fixtures, then `fmt -check` and `validate`.

The workflow token is read-only. Actions are pinned to commit SHAs. `terraform apply` is not a CI job.
