# Charter

Mere is an open-source data lake and the analytics on top of it. You deploy it on AWS with Terraform. You can check the numbers on a laptop with Node, before an account exists.

This repository is built on the [Agentic Foundry](https://github.com/jplabadie/agentic-foundry) structure. The founding set is the law. CI runs it. An agent that edits the lake without editing the law does not land.

The sample is eight orders. The fixtures say what those orders add up to. Athena, the local script, and the fixtures are one fact, not three.
